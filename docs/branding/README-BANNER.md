# Kosmos — GitHub README banner

Official banner application, supplemental to Branding v1.0.

- `kosmos-readme-banner.svg`: editable 1280 × 640 vector artwork.
- `kosmos-readme-banner.png`: 1280 × 640, ready for GitHub.
- `kosmos-readme-banner@2x.png`: 2560 × 1280, high-resolution export.

Uses the existing `logos/kosmos-dark-tagline.svg` paths and gradient unchanged, with one uniform scale and translation. Background: Void (#0D0912). No additional graphics, fonts or color tokens. Wordmark and tagline remain fixed vector contours.

From the repository root README, use:

```markdown
![Kosmos — The intelligence orbiting your world.](assets/branding/banners/kosmos-readme-banner.png)
```

The banner is a new application of the approved identity. No previous package entries are modified. SVG export rendered with CairoSVG; no runtime dependency is needed.
