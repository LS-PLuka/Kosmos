# Branding Package Index

This directory preserves the approved Kosmos branding and Motion Lab documentation. The original
documents are retained byte-for-byte, including their Portuguese language and historical statements.
Where a historical document says that a publication license had not yet been selected or describes
Kosmos as open source, the current repository-level policy supersedes that statement: Kosmos is
source-available under the PolyForm Noncommercial License 1.0.0.
